記事コンテンツ型LP サンプル
制作意図と設計方針

坂上／2026年8月

PPC広告からの流入を想定した記事コンテンツ型LPのサンプルです。ワイヤーフレームの作成からデザイン、HTML / CSS でのコーディングまで通しで制作しました。 ここでは「なぜこの作りにしたか」を記載します。

1.「広告」ではなく「記事」に見えることを最優先にした

記事コンテンツ型LPは、読者に「読み物」として受け取ってもらえた瞬間に機能します。そのため次の判断をしました。

  • ヘッダーにナビゲーションを置かない／メニューは離脱の入口になるため、ロゴとカテゴリ表示だけに絞る
  • 本文の横幅を最大640〜720pxに固定／1行が長いと読了率が落ちる。記事LPは横に広げないほうが強い
  • 本文16〜17px・行間1.9／スマートフォンで長文を読み切ってもらうための最低ライン
  • 見出し・図解・吹き出しでリズムをつくる／文字の壁が続くと途中で離脱される

2. PR表記をファーストビュー内に置いた

2023年10月施行のステルスマーケティング規制（景品表示法）により、広告であることの明示が必要です。 記事型LPは体裁が記事に寄るぶん配慮が要るため、スクロールしなくても見える位置に「PR｜この記事にはプロモーションが含まれます」を配置しました。ここを下部に隠す作りにはしていません。

3. CTAを4か所に分散した

記事LPは縦に長く、読者が離脱するタイミングがばらけます。1か所にまとめると取りこぼすため、読者の温度ごとに置き分けました。

位置想定する読者文言
解決策の直後もう決めている層ウィークミールを見てみる
料金の直後比較検討を終えた層お試しセットの詳細を見る
まとめの直後最後まで読んだ層初回半額でお試ししてみる
追従バー（SPのみ）どの位置からでも初回半額でお試しする

同じ文言を4回繰り返すと広告色が強く出るため、すべて変えています。

4. 数字を「図」にした

「平均72分」と書くだけでは自分ごとになりません。内訳をバーグラフにして、火を使っている時間は2割しかないことを目で分からせてから本題に入る構成にしました。 比較表も同様で、自社列だけ背景色を変えて視線を止めています。

5. スマートフォンから設計した

360〜430px幅で組み、min-width でタブレット・PCへ広げています。PCで先に作ってから縮めると、スマートフォンで文字組みが破綻します。

  • 追従CTAはスマートフォンのみ表示（PCでは画面を覆う必要がないため非表示）
  • 比較表は表の内側を横スクロールさせ、ページ全体は横に動かさない
  • 「表は横にスクロールできます」の案内をスマートフォンのみ表示
  • タップ領域はボタン高さ54〜68pxを確保

6. 表示速度のために外部読み込みをゼロにした

PPC流入は表示速度がそのまま費用対効果に効きます。そのため次のようにしました。

  • 画像・アイコンはすべてインラインSVG。画像リクエスト0件
  • Webフォント不使用（端末標準フォントで組む）
  • JavaScript不使用。FAQは <details>、目次はアンカーリンク、追従CTAは position: fixed で実装

外部ファイルはCSS1本のみです。

7. 細かい配慮

  • prefers-reduced-motion に対応（動きを減らす設定の端末ではアニメーションを止める）
  • キーボード操作時のフォーカス表示を確保
  • iPhoneのホームバーに追従CTAが隠れないよう env(safe-area-inset-bottom) で調整
  • 打ち消し価格と実売価格を同じ視野内・近接に配置（二重価格表示への配慮）

本番の案件での進め方

  1. ワイヤー・原稿・素材を受領し、着手前にセクション構成と想定工数を一覧でご確認いただく
  2. デザインを提出 → ご確認
  3. コーディング → 指定環境へ反映
  4. 表示確認（主要ブラウザ／スマートフォン実機相当）→ 修正対応

本サンプルは自作のワイヤーから起こしていますが、実案件では支給ワイヤーの意図を崩さないことを最優先にします。 デザイン面で気づいた点（可読性・離脱しやすい箇所・CTA前の導線など）は、勝手に変えずご提案の形でお伝えします。
